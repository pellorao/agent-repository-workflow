# 后续审核与问题处理

[结论复用](result-reuse.md)要求新判断时, 只对实际受影响的轴准备完整当前输入, 按[公共复审规则](../../../docs/agents/reviewer.md#review-changes-and-prior-coverage)检查相邻版本差异及关联影响, 并取得完整当前结果. 按技能主文件定义的身份复用可靠原线程.

Main Agent 需要中途结果时, 可以在审查期间读取各绑定报告文件. 对需要处理的问题独立核对后, 再请求必要的用户决定. 在每个适用轴交付其完整当前结果前, 固定的比较对象和完整输入副本保持不变. 这些审查进行时, 已授权修复可以在源工作树中推进; 每条结论只适用于其固定的受审版本, 改变后的最终候选按结论复用规则取得替代审查. 需要用户决定时按 `docs/agents/subagent-findings.md` 提供资料. 修订或撤回原位更新同一报告文件; 根据完成后的文件内容判断最终结果. 未完成文件不能替代每个轴所需的完整当前结果.

线程复用, 替代和重新连接按 [Reviewer 机器操作](../reviewer-launch/SKILL.md#machine-operations) 处理; 每轮新审查都准备新的空报告文件, 替代线程不接收旧问题, 作者讨论或修复历史. 不设固定复用次数或时限.

再次交付技能主文件要求的全部当前输入, 包括 Spec 轴完整治理要求, 以及公共规则允许的自身前轮原始报告和绑定输入. 先前问题, 修复位置和变化说明只提示需要核对之处, 不替代当前证据. 默认差异复审, 仍请求完整当前报告而非变化条目; 全盘例外由 Reviewer 按公共规则说明具体理由.

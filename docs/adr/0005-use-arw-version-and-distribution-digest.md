# 使用统一产品版本与工作流载荷摘要

## Decision

每次正式发布, 只要 ARW Engine 或供目标仓库使用的 Workflow Distribution 发生变化, 就必须产生新的 ARW Version. 工作流载荷没有独立的发布生命周期, 因而不另设版本号; 摘要值只标识该次发布所包含的准确载荷内容. 如果只有工作流载荷变化, 产品版本号和载荷摘要值都改变; 如果只有程序变化, 产品版本号改变, 未变化载荷的摘要值保持不变.

同一次产品发布需要一个统一身份, 供安装, 使用和发布验证共同引用. 载荷摘要值回答其中的工作流内容是否相同, 无须另行维护一套会与产品发布时序重复的版本号. 程序单独更新时保留原摘要值, 也让使用者能准确看出工作流内容没有随之改变.

`arw-lock.json` 的旧版持久字段决定已由 [ADR 0009](0009-use-canonical-distribution-lock-contract.md#decision) 取代. 当前锁文件不保存产品版本号或工作流载荷摘要值; 本记录负责发布身份及载荷识别的关系, 不定义锁文件结构.

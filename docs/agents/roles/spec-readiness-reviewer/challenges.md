# Spec Readiness Reviewer 挑战审查

只有执行 `docs/agents/subagent-findings.md` 允许的后续挑战审查时, 才读取本文档.

后续消息提供新的不可变 `Reviewer Request` 路径, 并可以指出以前的问题, 相关证据和 Main Agent 发现的具体推理错误. 新请求仍然是完整的审查材料, 并绑定新的 `draftPath`.

质疑消息只提示需要核对的具体问题, 不作为证据, 授权或偏好结论. 自身前轮材料的覆盖责任按[公共复审规则](../../reviewer.md#re-review)处理. 重新检查每个受到质疑的问题. 如果仍然保留问题, 必须具体回应质疑理由, 不得重复以前的文字. 质疑指出问题属于既有设计时, 保留该问题须指出本 issue 交付对缺失事实的具体依赖.

依据完整当前请求和公共复审规则形成全部适用检查的当前判断, 在新的绑定路径亲自写入完整替代草稿, 返回正常最终状态. 不把以前的草稿当成本轮输出, 不只返回差异.

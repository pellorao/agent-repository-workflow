# RESOURCES.md 格式

`RESOURCES.md` 是该主题下精选的可信来源. 讲解所用的知识应取自这里, 而不是参数化猜测. 智慧来自这里列出的社群.

## Structure

```md
# {主题}资源

## Knowledge

- [书: _The Science and Practice of Strength Training_ — Zatsiorsky & Kraemer](https://example.com)
  力量训练编排与适应的基础文本. 用于: 周期化, 恢复, 强度区间相关的一切.
- [文章: "How Much Should I Train?" — Greg Nuckols (Stronger By Science)](https://example.com)
  对训练量界标的循证综述. 用于: 每个肌群的每周组数目标.

## Wisdom (Communities)

- [r/weightroom](https://reddit.com/r/weightroom)
  高信号子版块, 管理上抵制 "健身房迷信". 用于: 计划点评, 平台期排查.
- 本地: {健身房名称}周二力量课
  用于: 对动作的实时指导反馈.
```

## Rules

- **只收高可信来源.** 优先一手资料, 公认专家, 同行评审的工作和管理严格的社群. 把营销包装成教育的资源不要收.
- **每条都要注释.** 三个月后一个光秃秃的链接毫无用处. 加一行: 涵盖什么, 何时查阅.
- **按 Knowledge / Wisdom 分组.** 与 [SKILL.md](./SKILL.md) 中的理念一致. 一个资源只出现在一组也可以.
- **明确暴露缺口.** 使命需要的某个领域没有好资源时, 写一个 `## Gaps` 章节列出缺什么, 推动后续搜索.
- **毫不留情地修剪.** 被证明有误, 肤浅或偏离使命的资源要删除, 不要埋没. 五个锋利的来源胜过三十个平庸的.
- **记录社群偏好.** 用户选择不加入社群时, 在此注明, 避免后续会话反复建议.

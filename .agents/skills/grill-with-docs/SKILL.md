使用 `$grilling` 组织讨论, 并使用 `$domain-modeling` 梳理领域模型和记录已确认的内容.

用户明确确认某项术语或决定后, 在发送下一轮问题前, 可以准备仅记录该项已确认内容的文档修改. 修改内容必须不依赖尚未解决的决定. 写入前遵循 [Agent 文件写入](../../../docs/agents/agent-writes.md) 和 [受保护文档审查](../../../docs/agents/rule-and-design-changes.md) 规则. 文档类型和记录条件由 `domain-modeling` 负责.

这些讨论记录可以在整体共识前准备. 所讨论计划的实施仍等待用户确认整体共识.
